# KYC Sentinel

**Adverse-media screening for AML/KYC analysts: Jev judges, code decides, the LLM only writes.**

Compliance analysts spend hours clearing irrelevant news hits: people with the same name, victims, passing mentions. KYC Sentinel pulls news for every client in a portfolio, has **Jev** judge each (client, article) pair (same person? the perpetrator? what risk? how severe?), and a **pure, deterministic router** sorts clients into `CLEAR / REVIEW / FLAGGED / NO_COVERAGE`.

## Why it's different

- **Fails closed.** Any uncertainty or Jev error means REVIEW, never CLEAR.
- **Autonomy Dial.** A compliance manager drags strictness, and the whole portfolio re-routes instantly from stored raw Jev probabilities, with **zero new model calls**.
- **Thresholds live in code, not prompts.** The router is the most heavily unit-tested module.
- **LLM on demand only.** Analyst memos are generated only for flagged/review clients, from Jev's structured facts, citing article URLs, and never making the decision.
- **Full audit trail.** Every decision is appended to `data/audit.jsonl`.
- **Receipts meter.** Shows calls, tokens, cost, and time against an LLM-equivalent estimate.

## Results (26-client portfolio)

| | |
|---|---|
| Jev calls | 37, with 0 errors |
| Wall time | 0.9 s |
| Jev cost | **$0.0011** |
| Same job via frontier LLM (est.) | $0.164 (**~145× more**) |

Outcome: **7 FLAGGED · 5 REVIEW · 10 CLEAR · 4 NO_COVERAGE**. All documented fraud cases were FLAGGED. Famous-name collisions (Michael Jordan, Tom Brady, Michael Cohen) were CLEARed as *different person*, even when the other person's news is adverse. Victims and identity-theft targets were CLEARed as *not the subject*. Vague common-name mentions went to **REVIEW** rather than being silently cleared. Taylor Swift (C008) shows both at once: the pop-star article is ignored and the Tulsa-accountant fraud charge is surfaced.

## Architecture

```
portfolio.csv ─► gdelt.py ─► news_cache.json
                                  │
                   screening.py (async, semaphore 8)
                                  │  per (client, article)
                   jev_client.py ──► Jev   (raw probabilities, never thresholded)
                                  │
                   router.py (pure: thresholds → verdicts → client status)
                                  │
     audit.py (JSONL) · receipts.py · results.json · memo.py ──► LLM
                                  │
                   api.py (FastAPI) ◄── static/index.html
```

## Run it

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env            # fill in JEV_* and LLM_* keys
python scripts/fetch_news.py    # optional: news is already cached
python scripts/run_screen.py    # judges everything, writes data/results.json
uvicorn app.api:app --port 8000 # open http://localhost:8000
pytest -q                       # 77 tests
```
